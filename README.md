# Personal Portfolio Website

This is the source code for my professional portfolio website. It showcases my technical projects, research interests, and professional background in AI and Computer Vision.

## Technologies Used
- HTML5
- CSS3 (Custom styling)
- Responsive Web Design

## Features
- Minimalist and professional dark-themed UI.
- Fast loading and mobile-friendly.
- Direct links to my GitHub repositories.

## Purpose
Designed to provide a centralized hub for my work, making it easy for recruiters and collaborators to explore my projects.
